# LPBF 熔池的 Rosenthal 解析基线

一个只问一件事的计算：只把激光当作匀速移动的点热源、只靠体导热，Ti-6Al-4V 的熔池能算多大？
先自检实现，再谈它离真实熔池有多远——后者本轮没有读文献，所以不下“偏大/偏小”的结论。

## 复现

```
MPCONFIGDIR=.mpl ../../.venv-pymatgen/bin/python model.py
```

产物：`out/results.json`、`out/summary.md`、`out/map.png`。

## 模型

Rosenthal 准稳态解：T = T0 + ηP/(2πkR)·exp(−v(R+x)/2α)，R 为到热源的距离，源沿 +x 移动。
Ti-6Al-4V 近似参数：k=7 W/mK、ρ=4430 kg/m³、cp=560 J/kgK（α=2.82e-6 m²/s）、Tm=1923 K、T0=298 K、η=0.4。

## 自检结果（全部通过）

- v=0 时应为球，数值半径与闭式 ηP/(2πkΔT) 相对误差 0；
- 熔池尾部长度与同一闭式一致（相对误差 0）；
- 模型内恒有“宽度 = 2×深度”；
- 边界温度残差 ~1e-13 K；P↑深度↑、v↑深度↓。

## 参考工况 P=200 W, v=1.0 m/s

- 深度 22.1 µm，宽度 44.3 µm，尾部长度 1119.3 µm。

## 一个值得记住的模型性质

尾部长度只由 ηP/(2πkΔT) 决定，**与扫描速度无关**（高速时尾部指数因子趋近 1）。
所以这个点源模型给出的熔池是 22 µm 深、44 µm 宽、1.1 mm 长的极细长形状（长宽比约 50:1）。
这是纯导热的数学后果，不代表真实熔池形状；真实熔池受对流、潜热、粉末与多重反射截断，形状更接近半椭圆/泪滴。
**要判断差多少，必须读实测熔池截面，本轮没有读，故不下结论。**

## 边界

解析基准，不是仿真、不是实验。材料参数是常用近似值，未逐条溯源。下一步应读 LPBF 热-流耦合模型的参数设置。
