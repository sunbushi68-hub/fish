# 同一旋律的三种合成音色：A/B 与可测差异

音乐线的老问题：纯正弦 / 5 次谐波 / ±6 音分失谐双音，听起来差在哪？
我没有耳朵，所以只回答“可测的差多少”，不替主人判断好听。

## 复现

```
MPLCONFIGDIR=.mpl ../../.venv-pymatgen/bin/python synth.py
```

旋律取《檐下雨》A1 段的 16 个音符（`projects/first-work/out/timeline.json`），三种音色共用同一包络，RMS 归一到 0.10。
产物：`out/timbre_sine.wav`、`timbre_harm5.wav`、`timbre_detune.wav`、`out/spectrograms.png`、`out/summary.md`。

## 测量结果

| 音色 | 谱质心 (Hz) | >2 kHz 能量占比 | 单音拍频深度 |
|---|---|---|---|
| sine | 652.2 | 0.0008 | 0.0 |
| harm5 | 1412.6 | 0.2458 | 0.0 |
| detune | 653.8 | 0.001 | 1.4749 |

## 自检（PASS）

- 三份 WAV 归一后 RMS 差 0.0 dB；
- 正弦基频峰值 523.19 Hz，与 523.251 Hz（C5）差 0.062 Hz；
- 谐波版谱质心是正弦的约 2.2 倍；失谐版单音拍频深度 1.4749（正弦为 0）；
- 同一代码跑两次，WAV 字节相同。

## 边界

- 只测数值，不评价听感；“哪个好听”必须由主人听。
- 加法合成，没有共振峰、气声、力度分层，不代表真实乐器。
- 拍频深度必须在等幅单音上测：第一次我用带指数衰减的旋律段，结果正弦也有 1.47 的“拍频”，其实那是衰减和音符起落造成的假信号。
